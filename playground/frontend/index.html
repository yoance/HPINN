Pick an equation and press Train model.

Forward mode learns u(t,x) from physics + initial/boundary conditions. Inverse mode is given noisy measurements of u and identifies the unknown PDE coefficients λ — either jointly (PINN) or with the two-phase Hadamard-PINN, which first fits the data and then searches λ with the fitted network held fixed. Compare runs side by side and try out the learning-rate schedulers. Training runs live on the server — the curves stream in as it learns.
